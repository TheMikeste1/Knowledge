The actions an [[Agents|Agent]] can perform on a component are categorized into three different categories:
- **Read**. The agent can read, listen to, or otherwise receive information from a component. ^66b87c
- **Write**. The agent can write to, modify, or otherwise provide information to a component. ^3abd84
- **Possess**. The agent can cause the component to do something on its behalf. ^56ffbc

What each of these actions means depends on the individual asset and component, but should generally mean the same or similar things within each asset. In rare cases, an action might not be applicable to a component. For example, it would be difficult to modify (or [[#^3abd84|write]] to) a human User in systems that do not include medical instruments.
