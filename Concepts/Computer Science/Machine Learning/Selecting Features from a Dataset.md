Datasets often have more variables than required or even desired. Too many variables make it difficult for humans to reason about, and can also cause issues for machine learning models by requiring them to handle dimensions they don't need. This also increases resource requirements for models.

To solve these issues, we can select a subset of variables from the dataset.
