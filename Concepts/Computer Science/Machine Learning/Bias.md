*Bias* is used to offset a [[Machine Learning]] algorithm so it can better fit the desired data. It essentially shifts the [[y-intercept]] so the line produced can better reach the data. An easy example of a bias is the $b$ in $y = mx + b$, such as in [[Linear Regression]]. In [[Neural Network|neural networks]], it is common to add an incoming bias node of 1 to each hidden layer.
