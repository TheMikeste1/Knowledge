# Reinforcement Learning
The machine is given only a small amount of information, perhaps few bits, per sample.

The machine predicts a scalar reward given once in a while, typically positive when it does something good or negative when it does something bad.


# Supervised Learning
The machine is given 10 -> 10,000 bits per sample. This is not a lot, but it if a decent amount.

This is typically used to predict a category or a few numbers for each input using human-supplied data.


# Self-Supervised / Unsupervised / Predictive Learning
The machine is given millions of bits per sample.

This can be used for applications such as predicting future frames in videos. The machine predicts any part of its input for any observed part.
