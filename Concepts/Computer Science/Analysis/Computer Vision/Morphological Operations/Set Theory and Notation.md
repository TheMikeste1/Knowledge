- Translation
$A_x = \{ c | c = a + x, a \in A \}$
- Reflection
$\hat{A} = \{ c | c = -a, a \in A \}$
- Complement
$A^c = \{ c | c \notin A \}$
- Intersection
$A \cap B = \{ c | (c \in A) \land (c \in B) \}$
- Union
$A \cup B = \{ c | (c \in A) \lor (c \in B) \}$
- Difference
$A - B = \{c | (c \in A) \land (c \notin B) \}$
- Subset
$A \subseteq B = \{c | if\;c \in A, then\;c \in B \}$
- Disjoint (Mutually exclusive)
$A \cap B = \phi$, where $\phi$ is the empty set. This means $A$ and $B$ do not have any elements in common
