# Window manipulation
- `zz` Move current line to middle of screen
- `zt` Move current line to top of screen
- `zb` Move current line to bottom of screen
# Text manipulation
- `cw` Delete to end of `word`
- `cW` Delete to end of `WORD`
- `yy` Copy current line
- `3yy` Copy the next 3 lines, starting with the current line
- `y^` Copy from the start of the line to the cursor
- `yiw` Copy the current word
