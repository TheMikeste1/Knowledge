Object Kinds contain information about the build system. Each object contains the `"kind"` and the `"version"` followed by the kind-specific data.
```json
{
  "kind": "<kind>",
  "version": { "major": 1, "minor": 0 },
  "<kind-specific-data>": {}
}
```
