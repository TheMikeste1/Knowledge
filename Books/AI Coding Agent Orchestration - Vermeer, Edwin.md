**Abstract**:: This configuration guide is an opinionated but practical handbook that argues for treating AI coding tools as a composable, multi-agent system rather than a single assistant, and then walks through how to implement that mindset using OpenCode's CLI, configuration system, and ecosystem (agents, tools, skills, and plugins). It emphasizes that productivity gains come from structured context, explicit orchestration, and layered configuration (global -> project -> runtime), enabling developers to build a repeatable “AI team” that plans, codes, reviews, and integrates work with minimal manual prompting.
