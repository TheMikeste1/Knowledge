## Notes

- Idea -> Spec -> Ticket(s) -> Implementation
    - "Tickets" aren't always Jira/Github issues. A large issue may need to be decomposed for the agent
- Before writing code, perform four review to catch issues in the spec and tickets. Some of these can be automated, but the developer should also take on each role.
    1. Senior Engineer
    2. Architect
    3. Security Officer
    4. Product Manager
- Surface ambiguities and questions early
- TDD can be very beneficial for agents
